# Protocol Synapsix — mobile

Flutter client for SIH26168 (intelligent dead-reckoning). This tree is a
**demo skeleton**: five pipeline agents are labeled mocks.

```
flutter pub get
flutter run
```

Open **Home / Map** after onboarding. The tunnel GNSS-loss cycle runs
automatically (tight ellipse → Dead-Reckoning Active ~20s → snap back).

Hidden debug chart: Settings app-bar title × 7 taps.
